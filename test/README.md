# Testing the Evaluation Processes
These are tests of the evaluation processes in `src/`.  To ensure the reliability of the scores generated there, we run the evaluation processes on some simple output files whose various scores have been manually calculated, and confim that the scores outputted by the evaluation match those scores.

`./test_data/` contains all the files used for these tests.  Each number corresponds to a different test.

`test_eval.sh` is the control centre of the tests.  It includes the manually-determined exepected evaluation results for each test.  It calls `test_eval.py` for each test, which compares those expected results to those generated by the evaluation scripts, which are stored in a CSV.

Because the segmentation, glossing, and pipeline (i.e., combined seg + gloss) processes all have different evaluation scripts, each kind of evaluation is tested indiviudally.  You'll notice this in the output from `test_eval.sh`: each test is preceded by a label such as "Segmentation Test 1" that indicates which stage it is testing.

Run the tests with `sh test_eval.sh` (run from inside this subdir).
